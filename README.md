# OOP Concepts in C++

This project contains simple C++ programs created to understand and practice the basic concepts of Object-Oriented Programming. The programs demonstrate how classes and objects are created and how concepts like encapsulation, inheritance, abstraction, and polymorphism are used in C++.

## Technology Used

* **Programming Language:** C++
* **Compiler:** Any standard C++ compiler
* **Concepts:** Classes, Objects, Encapsulation, Inheritance, Abstraction, Virtual Functions, Abstract Classes, and Polymorphism
